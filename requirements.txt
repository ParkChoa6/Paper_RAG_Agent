# ⚠️⚠️ torch 要【单独装】，不能靠 `pip install -r requirements.txt`。
#
# 原因：我们要的是 **CPU 版** torch，而它的版本号带 `+cpu` 本地标记，
#       这个 wheel 只在 PyTorch 自己的索引上，**PyPI 上没有**。
#       写在下面这一行会让 -r 直接失败（找不到这个版本）。
#
# 所以重建环境是【两步】：
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#     pip install -r requirements.txt
#
# ★ 为什么不把 `--extra-index-url` 写进本文件让它一步装完：
#   extra-index-url 的解析顺序是【所有索引一起看，谁版本高用谁】——
#   等于把 PyPI 上任何叫 torch 的包都变成候选。这是个已知的
#   依赖混淆（dependency confusion）面。宁可多打一条命令。
#
# ★ 为什么是 CPU 版不是 CUDA 版：
#   ① 体积：CPU 版约 200MB，CUDA 版约 2.5GB
#   ② ★ 显存：那台 4070 的 12GB 要留给 Ollama（qwen2:7b 生成占约 4.5GB）。
#      再塞一个 568M 的 reranker 进去，撞墙时的现象是【Ollama 那边超时】，
#      看不到 rerank 的错 —— 又是一次「错了但不报错」。
#   ③ 实测重排 20 条候选在 CPU 上约 1~2 秒，评测 28 题够用。
#
# ⚠️ 装它只为了 Stage 5 的 cross-encoder 重排（paper_rag/rerank.py）。

#    而它架构上也跑不了 cross-encoder（它是给 tokens→文本 的生成式模型设计的）。
#    所以这一条依赖是【绕开 Ollama】的，不是它的一部分。
